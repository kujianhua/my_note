# 苏州五峰山中国地图

# 城市

苏州

# 地址

吴中区木渎镇森林消防中队

# 交通

火车（苏州站）、打车

# 日期

2024年11月02日

# 时间

09:00苏州站集合

# 强度

长度10.23km，爬升326m,预计用时3.5小时 线路详情 (opens new window)

# 费用

火车票自购，打车费AA

# 注意事项

必备：运动装，运动鞋，背包 带一顿路上吃的饭，零食、面包、馒头、卤货、糖果、辣条... 饮用水、电解质水

# 结束后

建议定好酒店，当天住下，晚上和第二天可游玩苏州:博物馆、园林... 也可以根据情况再买返程车票

自愿参与，责任自负

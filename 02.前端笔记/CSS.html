# content

CSS 的 content CSS 属性用于在元素的 ::before 和 ::after 伪元素中插入内容。使用content 属性插入的内容都是匿名的可替换元素。 Chrome支持正常元素插入。 可用属性

  1. string （可直接明文，也可编码字符）
  2. none
  3. quote
  4. url
  5. attr
  6. counter

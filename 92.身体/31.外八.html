# 外八

# 基本表现

  • 自由站立，双脚脚尖角度过大；
  • 鞋跟外侧磨损严重；

# 原因

  • 主观觉得外八走路就是拽
  • 髋外旋肌过紧，造成股骨外旋
  • 股二头肌过紧，造成胫骨外旋
  • 大腿内收肌群力量薄弱
  • 臀大肌紧张
  • 足弓塌陷

# 影响

  • 足弓塌陷，形成扁平足
  • 膝盖受力不均，导致膝盖软骨异常磨损，久之膝痛

# 连锁反应

外八长时间步行，腿外旋，股内侧肌较多的承担脚落地时的冲击力，从而导致，股内侧肌与股外侧肌力量失衡， 然后就导致髌骨左右被牵拉力量不均衡，导致髌骨存在侧滑，长时间异常磨损造成髌骨软化；膝盖就痛起来了。
